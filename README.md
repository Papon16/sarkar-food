# 🍔 SarkarFood

A Laravel-based food website developed as a web application project.  
The project is containerized using Docker to provide a consistent development environment.

## 📌 Project Overview

SarkarFood is a food website built with the Laravel framework. The project provides a structured web application environment for developing and managing food-related web functionality.

Docker is used to containerize the Laravel application so that the project can run in an isolated and consistent environment.

## ✨ Features

- 🍔 Food website interface
- 🌐 Laravel-based web application
- 🗄️ SQLite database
- 🐳 Docker containerization
- ⚙️ Docker Compose configuration
- 🎨 Blade-based frontend
- 📱 Responsive web interface
- 🔧 Easy local development setup
